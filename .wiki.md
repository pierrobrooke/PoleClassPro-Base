# Project Summary
**PoleClass Pro** has evolved into a Movement Intelligence Platform™—a comprehensive movement education technology company. While pole fitness remains the initial focus, the platform is designed to encompass various disciplines such as Pilates, aerial arts, dance education, and more. It emphasizes educational authority, structured progression, and movement science, providing instructors with tools for curriculum design, development, and a hopeful future. The brand aims to convey authority and optimism, moving away from traditional pole dance imagery.

# Project Module Description
The project consists of several functional modules, including:

- **Preview Service**: Real-time rendering for instant updates.
- **App Viewer**: Displays the current application state during development.
- **Data Layer**: Manages pole move data and reference materials via Supabase.
- **Loading Indicators**: Enhanced user experience with subtle spinners.

# Technology Stack
- **Node.js**: JavaScript runtime for building the application.
- **pnpm**: Package manager for managing dependencies.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Supabase**: Backend as a service for managing data and reference materials.

# Usage
To set up the project, follow these steps:
1. Navigate to the frontend directory:
   ```bash
   cd /workspace/app/frontend
   ```
2. Create a `.env` file with your Supabase key:
   ```bash
   echo "VITE_SUPABASE_ANON_KEY=<your_supabase_key>" > .env
   ```
3. Install dependencies using pnpm:
   ```bash
   pnpm install
   ```
4. Build the project:
   ```bash
   pnpm run build
   ```
5. Start the preview service to view the application.
